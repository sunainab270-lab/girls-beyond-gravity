# Deployment Notes

The local MVP runs without paid services. Production deployment will need:

- Hosted application runtime.
- PostgreSQL-compatible database.
- Secure authentication secret.
- Role-based authorization.
- Email provider.
- AI provider if enabled.
- Storage provider for portfolio files.
- Monitoring and audit logging.
- Privacy, terms, safeguarding, accessibility, and AP trademark review.

Never place secrets or API keys in source code.
