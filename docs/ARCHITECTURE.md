# Architecture

The MVP is a Next.js and TypeScript site with centralized brand configuration, seeded demo data, reusable business logic, and a single polished product surface.

Long-term architecture:

- Next.js App Router frontend.
- Strict TypeScript application code.
- Tailwind-based design system.
- PostgreSQL-compatible relational database.
- Prisma ORM or equivalent migration workflow.
- Secure authentication and server-side authorization.
- Zod validation and React Hook Form for complex forms.
- Provider adapters for AI, email, maps, news, storage, translation, and video.
- Role-based admin tools for verification, moderation, publishing, and audits.

The local MVP does not require paid services.
