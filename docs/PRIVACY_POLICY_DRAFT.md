# Privacy Policy Draft

Draft only. Requires qualified legal review before launch.

Beyond Gravity should collect the minimum data needed for learning personalization, safety, and opportunity matching. Exact home addresses should not be requested. Public profiles should never show exact age, personal contact details, school schedules, or exact student location.

Users should be able to export data, delete accounts, control portfolio sharing, revoke shared links, and clear AI tutor chat history where applicable.
