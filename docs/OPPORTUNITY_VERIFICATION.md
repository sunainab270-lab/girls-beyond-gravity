# Opportunity Verification

Every time-sensitive record needs source, last checked date, verification status, reviewer, expiration or next-review date, and staff notes.

The MVP uses fictional demonstration records. Production records must never invent deadlines, eligibility rules, organizations, application links, visa advice, citizenship restrictions, or testing-center policies.

Default labels:

- Excellent match
- Possible match
- Check eligibility
- Not currently eligible
- Deadline passed

Expired opportunities should not appear by default. Incomplete legal eligibility must be shown as missing information, not inferred eligibility.
